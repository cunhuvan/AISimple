Theme là "bộ quần áo" của website — quyết định 80% cảm giác đầu tiên của khách truy cập. Chọn đúng theme giúp website trông chuyên nghiệp ngay cả khi bạn không phải nhà thiết kế.

## Tiêu chí chọn theme

### 1. Tốc độ
Theme nặng = website chậm = mất khách. Chọn theme được quảng cáo là **nhẹ, tối ưu tốc độ**. Tránh theme "all-in-one" nhét hàng trăm tính năng.

### 2. Tương thích với trình chỉnh sửa khối
Chọn theme tương thích với **Gutenberg** (trình soạn thảo mặc định của WordPress) — bạn sẽ dễ dàng chỉnh sửa mà không cần code.

### 3. Responsive
Theme phải hiển thị đẹp trên điện thoại. Hầu hết theme hiện đại đều có, nhưng hãy kiểm tra bản demo trên điện thoại thật.

### 4. Được cập nhật thường xuyên
Theme ngừng cập nhật = rủi ro bảo mật. Kiểm tra ngày cập nhật gần nhất.

### 5. Hỗ trợ tiếng Việt
Chữ tiếng Việt có dấu phải hiển thị đẹp. Hầu hết theme hiện đại đều ổn, nhưng kiểm tra font trong bản demo.

## Nguồn theme đáng tin cậy

- **Kho theme trong WordPress** (Giao diện → Thêm mới): miễn phí, được kiểm duyệt, an toàn. **Nơi tốt nhất cho người mới.**
- **Theme Forest / ThemeForest:** trả phí, nhiều lựa chọn đẹp.
- **Trang chủ của hãng theme nổi tiếng** (GeneratePress, Kadence, Astra...).

> **Cảnh báo:** KHÔNG tải theme từ các trang web lạ, crack, "theme premium miễn phí". Đó là cách phổ biến nhất để website bị cài mã độc.

## Cách cài theme

### Từ kho theme WordPress (an toàn nhất)
1. Vào **Giao diện → Thêm mới**.
2. Tìm kiếm tên theme hoặc duyệt theo danh mục.
3. Bấm **Cài đặt**, sau đó **Kích hoạt**.

### Từ file zip (theme trả phí)
1. Vào **Giao diện → Thêm mới → Tải giao diện lên**.
2. Chọn file `.zip` và bấm Cài đặt.
3. Kích hoạt.

## Sau khi cài: 3 việc nên làm

1. **Xem website ở tab mới** — đánh giá nhanh: có đẹp không, có đúng ngành nghề không.
2. **Vào Giao diện → Tùy chỉnh** (hoặc Customizer) — đổi logo, màu chủ đạo, font chữ.
3. **Đừng đổi theme liên tục.** Mỗi lần đổi theme là mỗi lần phải chỉnh lại. Chọn một theme tốt và gắn bó.

> **Điểm mấu chốt:** Chọn theme nhẹ, được cập nhật, từ nguồn tin cậy. Một theme tốt + vài phút tùy chỉnh = website trông chuyên nghiệp hơn 90% website tự làm khác.
