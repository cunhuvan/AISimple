Plugin là "ứng dụng mở rộng" cho WordPress. Cài đúng plugin, website của bạn thêm tính năng mà không cần viết code. Nhưng cài quá nhiều plugin là cách nhanh nhất để làm chậm và làm hỏng website.

## Nguyên tắc vàng: càng ít càng tốt

Mỗi plugin là một đoạn mã chạy trên website. Càng nhiều plugin, website càng chậm và càng dễ bị lỗi. **Chỉ cài plugin bạn thật sự cần.**

## 5 plugin thiết yếu cho người mới

### 1. Plugin sao lưu: UpdraftPlus
Tự động sao lưu website (xem bài 9.1). Bản miễn phí là đủ cho người mới.

### 2. Plugin bảo mật: Wordfence (hoặc Solid Security)
Chặn tấn công, quét mã độc, cảnh báo đăng nhập lạ (xem bài 9.2).

### 3. Plugin SEO: Rank Math (hoặc Yoast SEO)
Hướng dẫn bạn tối ưu từng bài viết cho Google (xem chương 8). Rank Math bản miễn phí rất tốt.

### 4. Plugin tốc độ: LiteSpeed Cache (hoặc WP Super Cache)
Tạo bản sao tĩnh của website để tải nhanh hơn. Chọn theo nhà hosting của bạn.

### 5. Plugin biểu mẫu: Contact Form 7 hoặc WPForms
Tạo form liên hệ, đặt hàng mà không cần code.

## Plugin nên né xa

- **Plugin "tất cả trong một"** nhét hàng trăm tính năng — nặng và dễ xung đột.
- **Plugin crack, "premium miễn phí"** từ web lạ — chứa mã độc.
- **Plugin không còn cập nhật** từ lâu — lỗ hổng bảo mật.
- **Plugin trùng chức năng** — hai plugin làm cùng một việc là thừa.

## Cách cài plugin an toàn

1. Vào **Plugin → Thêm mới**.
2. Tìm kiếm tên plugin.
3. Kiểm tra: **số lượt cài đặt** (nên trên 100.000), **đánh giá** (4 sao trở lên), **ngày cập nhật gần nhất** (dưới 6 tháng).
4. Bấm **Cài đặt → Kích hoạt**.

## Sau khi cài: kiểm tra tốc độ

Sau mỗi lần cài plugin mới, hãy mở website và kiểm tra nhanh xem có chậm hơn không. Nếu website đột nhiên chậm rõ rệt sau khi cài một plugin, hãy **vô hiệu hóa plugin đó** và tìm giải pháp khác.

## Quy tắc dọn dẹp định kỳ

Mỗi quý một lần:

- Vào **Plugin → Đã cài đặt**.
- Xóa các plugin không dùng (không chỉ vô hiệu hóa, mà **xóa hẳn**).
- Cập nhật tất cả plugin còn dùng.

> **Điểm mấu chốt:** Bắt đầu với 5 plugin trên là đủ cho mọi website cơ bản. Ít plugin = nhanh + an toàn + dễ quản lý. Mỗi lần muốn cài thêm, hãy tự hỏi: "Website của tôi thật sự cần nó không?"
